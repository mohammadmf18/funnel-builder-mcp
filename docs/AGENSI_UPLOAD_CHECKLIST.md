# Agensi upload checklist (not submitted)

Product: **AI Sales Funnel Builder — MCP Marketing Funnel Skill**

Pricing: **Subscription, USD 15 per month**. Do not turn on annual billing at launch.

1. Sign in to Agensi with Google and enable Creator Mode.
2. Connect payout method as supported in your country.
3. Download the GitHub Actions artifact `ai-sales-funnel-builder-agensi-zip`; extract it to obtain `ai-sales-funnel-builder-agensi.zip`.
4. In Agensi seller dashboard, start a new Skill listing and upload this ZIP. Verify `SKILL.md` is at the ZIP root and frontmatter has `name` and `description`.
5. Choose **Subscription** and **$15/month**; yearly plan disabled.
6. Use the description in `docs/AGENSI_LISTING.md`, explain that it needs a separate locally installed Funnel Builder MCP server and does not host or process live transactions.
7. In “Needs access to” state **local Funnel Builder MCP server** and Python 3.10+.
8. Review the security scan and listing preview; only submit when details are accurate.
9. Confirm receipt and review outcome in Agensi before claiming the listing is live.

Agensi cannot install or run the Python MCP server for buyers. The marketplace ZIP includes text instructions, not executable app code.
