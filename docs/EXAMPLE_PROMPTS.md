# Example prompts

Use these examples after configuring the separate Funnel Builder MCP server. These prompts use mockup and static export only.

## Lead generation
Create a funnel for a free beginner photography guide targeting first-time camera owners. Make a landing page, opt-in page and thank-you page, use plain-language copy, and export static HTML. Make clear the opt-in form is a nonfunctional mockup.

## Digital course
Draft a funnel for an online design course priced at 49 USD. Create landing, sales, checkout mockup, optional upsell and thank-you pages. Use only substantiated benefits and do not claim secure card payment is implemented.

## Reporting
List the available funnel drafts and summarize any manually recorded events for the latest funnel. If there are no recorded events, state that analytics are empty rather than inventing conversions.
